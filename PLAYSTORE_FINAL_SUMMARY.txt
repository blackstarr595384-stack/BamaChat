================================================================================
                      🚀 QUICK START (30 minutes)
================================================================================

STEP 1: Firebase Setup (10 min)
  1. Go to: https://console.firebase.google.com
  2. Create project "BamaChat"
  3. Add Android app (Package: com.example.bamachat)
  4. Download google-services.json
  5. Copy to: app/src/main/google-services.json

STEP 2: Integrate Screens (10 min)
  In OnboardingScreen or WelcomeScreen, add:
  
  LegalDisclaimerScreen(
      onAccept = { settingsViewModel.setLegalAccepted(true) },
      onBack = { /* close */ }
  )
  
  OnboardingAPIKeySetupScreen(
      onComplete = { openRouter, groq ->
          settingsViewModel.setOpenRouterApiKey(openRouter)
          settingsViewModel.setGroqApiKey(groq)
      },
      onSkip = { /* continue */ }
  )

STEP 3: Build & Test (10 min)
  ./gradlew assembleRelease
  adb install app/build/outputs/apk/release/app-release-unsigned.apk
  
  Test on real device:
  • Offline mode: Disable internet, write message, enable internet
  • Legal: Does legal screen appear?
  • API-Key: Does setup wizard appear?
  • Crashes: Check Firebase Console
