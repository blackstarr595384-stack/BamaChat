# Play Console Hinweis: AI Image Tools

Wenn BamaChat externe Bildgeneratoren oeffnet, sollte in der Play Console und Datenschutzerklaerung klar beschrieben werden:

- Externe Bildgeneratoren werden im Browser geoeffnet.
- BamaChat sendet Prompts oder Bilder nicht ueber eine eigene inoffizielle API an diese Dienste.
- Nutzer geben Inhalte direkt beim externen Anbieter ein.
- Es gelten die Datenschutz- und Nutzungsbedingungen des externen Dienstes.
- Vor kommerzieller Nutzung erzeugter Bilder sollten die jeweiligen Bildrechte geprueft werden.

Wenn BamaChat selbst keine Prompts/Bilder an diese Anbieter uebertraegt, sondern nur den Browser oeffnet, sollte dies als externer Link/externes Tool beschrieben werden.
