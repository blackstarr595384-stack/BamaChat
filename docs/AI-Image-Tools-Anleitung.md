# BamaChat AI Image Tools Anleitung

## Zweck

AI Image Tools ist ein sicherer Hub fuer externe Bildgeneratoren. BamaChat oeffnet Dienste wie FreeForAI und Raphael AI extern im Browser.

## Warum extern?

Diese Variante ist bewusst sicher gewaehlt:

- keine inoffizielle API
- kein Scraping
- keine versteckten Zugangsdaten
- weniger Risiko fuer Play-Store- und Nutzungsbedingungen

## Nutzung

1. BamaChat oeffnen.
2. **Mini-Apps** oeffnen.
3. **AI Image Tools** waehlen.
4. Bei FreeForAI oder Raphael AI auf **Extern oeffnen** tippen.
5. Bild direkt beim Anbieter erstellen.
6. Zurueck zu BamaChat wechseln.

## Datenschutz-Hinweis

Wenn ein externer Bildgenerator geoeffnet wird, erfolgt die Eingabe und Verarbeitung von Prompts oder Bildern direkt beim jeweiligen Anbieter. Es gelten dessen Datenschutz- und Nutzungsbedingungen.

## Hinweis zu Bildrechten

Vor kommerzieller Nutzung erzeugter Bilder sollten die Nutzungsrechte des externen Dienstes geprueft werden.
